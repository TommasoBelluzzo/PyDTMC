
Installation
============

| PyDTMC requires **Python 3.12 or greater**.
| Its core dependencies include: `NumPy <https://numpy.org/>`_, `SciPy <https://scipy.org/>`_, `NetworkX <https://networkx.org/>`_, and `Matplotlib <https://matplotlib.org/>`_.

The library can be installed from `PyPI <https://pypi.org/project/PyDTMC/>`_:

.. code-block:: console

   python -m pip install pydtmc

Or, alternatively, from `conda-forge <https://anaconda.org/conda-forge/pydtmc>`_:

.. code-block:: console

   conda install -c conda-forge pydtmc

To install the latest development version from `GitHub <https://github.com/TommasoBelluzzo/PyDTMC>`_:

.. code-block:: console

   python -m pip install git+https://github.com/TommasoBelluzzo/PyDTMC.git

| For advanced graph visualization, `Graphviz <https://graphviz.org/>`_ and `pydot <https://pypi.org/project/pydot/>`_ are recommended.
| The former is a separate system installation, while the latter is a Python library.
